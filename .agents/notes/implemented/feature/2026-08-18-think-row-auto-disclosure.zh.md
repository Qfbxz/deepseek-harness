# Agent Note：Think 行跟随流式尾部、落定后折叠

Status: implemented

[English](2026-08-18-think-row-auto-disclosure.md) | 中文

## 问题

推理展示行（`ReasoningRow`）起初折叠，只有点击才展开。当块是流式尾部时，推理正被实时写出，行却缩在摘要行后面——模型正在进行的思考恰在最相关时刻不可见，且每个块的第一次交互都是一次本不必要的点击。

## 决策

该行是相位跟随者，手动覆盖仅当前相位内有效：`expanded = override ?? running`。块流式期间行展开、摘要跟随最新行；块落定后行折叠回摘要行。点击固定用户选择直到 running 相位翻转，随后自动跟随恢复——流式中的折叠对该块余下部分保持，下一块自行展开。相位翻转在以 `running` 为键的 `useEffect` 中重置覆盖，而非点击时，使固定在相位内的任意多次重渲染中存活。

## 备选方案

- **手动切换固定整行生命周期**（被替代的早期形态）。流式中一次折叠会静默吃掉后续所有块的自动展开；用户反馈行「再也不展开了」。
- **悬停展开代替相位展开。** 悬停在触屏不可用且隐藏特性；流式尾部是数据状态而非指针状态。

## 影响

落定行的行为不变（折叠为单行摘要）；仅流式尾部行为不同。覆盖是组件状态中的 `boolean | null`——无 store，该事实属每行且随行消亡。

## 测试

重写的 spec 钉住完整相位链：流式展开、手动折叠在流式相位余下部分固定且摘要跟随最新行、相位翻转清除覆盖回到落定折叠、落定摘要恢复首行。
